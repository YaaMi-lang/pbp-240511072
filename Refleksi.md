## Refleksi Pembelajaran

Setelah mengerjakan tugas pertemuan pertama mata kuliah Pemrograman Berbasis Platform, saya menjadi lebih memahami bahwa aplikasi dapat dikembangkan untuk berbagai platform, yaitu Web, Desktop, dan Mobile. Saya tertarik mempelajari ketiganya karena setiap platform memiliki cara kerja dan kegunaan yang berbeda. Aplikasi Web dapat diakses melalui browser, aplikasi Desktop digunakan melalui komputer, sedangkan aplikasi Mobile lebih praktis untuk digunakan melalui smartphone. Saya berharap dengan mempelajari ketiga platform tersebut, saya bisa mendapatkan lebih banyak pengalaman dalam membuat aplikasi.

Selama melakukan persiapan, ada beberapa hal yang cukup menantang bagi saya. Salah satunya adalah menghubungkan repository GitHub dengan komputer menggunakan Git. Pada awalnya, saya sempat mengalami kesulitan karena perintah yang digunakan belum sesuai dengan alamat repository yang sebenarnya. Selain itu, saat menginstal Java, saya juga perlu memperhatikan lokasi penyimpanan agar instalasinya berjalan dengan baik. Saya juga belajar menggunakan terminal untuk memeriksa versi aplikasi yang sudah terpasang.

Untuk mengatasi kendala tersebut, saya mencoba mengikuti langkah-langkah instalasi secara bertahap dan memeriksa kembali setiap perintah yang dijalankan. Jika mengalami kesulitan, saya akan mencari petunjuk dari Youtube atau meminta bantuan agar dapat memahami penyebab masalahnya. Ke depannya, saya ingin lebih terbiasa menggunakan Git, GitHub, dan berbagai tools pemrograman supaya proses pengembangan aplikasi menjadi lebih mudah.
