# Mengenal Perbedaan Platform Web, Desktop, dan Mobile

## 1. Pendahuluan

Dalam pengembangan aplikasi, ada beberapa platform yang bisa digunakan sesuai kebutuhan. Tiga di antaranya adalah Web, Desktop, dan Mobile. Walaupun sama-sama digunakan untuk menjalankan aplikasi, ketiganya memiliki cara kerja dan karakteristik yang tidak sepenuhnya sama. Oleh karena itu, penting untuk memahami perbedaan masing-masing platform agar kita bisa menentukan pilihan yang tepat ketika membuat sebuah aplikasi.

## 2. Perbandingan Platform

| Aspek | Web | Desktop | Mobile |
|---|---|---|---|
| Bahasa utama | HTML, CSS, dan JavaScript. TypeScript juga sering digunakan untuk proyek yang lebih terstruktur. | Java, C#, C++, dan Python, tergantung teknologi yang digunakan untuk membuat aplikasinya. | Kotlin dan Java untuk Android, Swift untuk iOS, serta Dart untuk aplikasi berbasis Flutter. |
| Arsitektur | Biasanya menggunakan browser sebagai tempat aplikasi dijalankan. Data dapat diproses di perangkat pengguna maupun melalui server. | Aplikasi dipasang di komputer dan dijalankan melalui sistem operasi, misalnya Windows, Linux, atau macOS. | Aplikasi berjalan di perangkat seperti smartphone dan tablet dengan memanfaatkan fitur yang tersedia pada sistem operasinya. |
| Cara distribusi | Pengguna cukup membuka alamat situs melalui browser. Pengembang dapat memperbarui aplikasi tanpa meminta pengguna mengunduh versi baru secara manual. | Aplikasi dapat dibagikan melalui installer, situs resmi pengembang, atau toko aplikasi desktop. | Aplikasi bisa diperoleh melalui Google Play Store, Apple App Store, atau metode instalasi lain yang sesuai dengan perangkat. |
| Keunggulan | Bisa dibuka dari berbagai perangkat selama browser mendukungnya. Pengguna juga tidak harus memasang aplikasi khusus untuk mengaksesnya. | Cocok untuk pekerjaan yang membutuhkan pengolahan data atau penggunaan sumber daya komputer. Aplikasi juga dapat dirancang agar tetap berfungsi tanpa internet. | Mudah dibawa dan digunakan di mana saja. Aplikasi juga dapat memanfaatkan fitur smartphone, seperti kamera, GPS, dan sensor lainnya. |
| Keterbatasan | Pengalaman penggunaan bisa dipengaruhi oleh koneksi internet, kemampuan browser, dan kondisi server. Tidak semua fitur perangkat dapat diakses secara bebas. | Pengembang perlu memperhatikan perbedaan sistem operasi dan perangkat yang digunakan. Pengguna biasanya juga perlu melakukan instalasi terlebih dahulu. | Kapasitas baterai, ukuran layar, dan memori perangkat dapat membatasi penggunaan aplikasi. Pengembang juga perlu mempertimbangkan variasi perangkat dan versi sistem operasi. |
| Contoh aplikasi | Gmail versi web, Google Docs, dan sistem informasi akademik berbasis web. | Visual Studio Code, aplikasi pengolah kata versi desktop, dan program kasir yang dipasang di komputer. | WhatsApp di smartphone, Google Maps, dan aplikasi mobile banking. |

## 3. Kesimpulan

Dari perbandingan tersebut, dapat diketahui bahwa setiap platform mempunyai kelebihan dan kekurangan masing-masing. Web lebih praktis ketika aplikasi perlu diakses melalui browser, Desktop dapat menjadi pilihan untuk pekerjaan yang dilakukan di komputer, sedangkan Mobile lebih sesuai untuk penggunaan melalui smartphone. Menurut saya, pemilihan platform sebaiknya tidak hanya berdasarkan teknologi yang digunakan, tetapi juga mempertimbangkan kebutuhan pengguna dan tujuan aplikasi yang akan dibuat.
